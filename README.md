# 🧮 우테코 프리코스 1주차 미션 - 문자열 덧셈 계산기
<br>

## 기능 구현 목록

### 입력, 출력
- 사용자가 입력한 문자열을 받음. (Console.readLine() 사용)
- 빈 문자열("")일 경우 0을 반환. (입력이 null인 경우도 0 반환)
- 계산 결과를 "결과 : n" 형식으로 출력.

### 커스텀 구분자 파싱
- 입력이 "//"로 시작하면 커스텀 구분자 형식으로 간주.
- 구분자와 본문을 분리.
 
### 기본 구분자 처리
- 커스텀 구분자가 없는 경우, 기본 구분자인 쉼표(,) 콜론(:)을 사용하여 숫자를 분리.
- 모든 숫자를 더한 합계를 구해 반환.

### 예외 처리
- 공통
  - System.exit()를 호출하지 않고, 예외 발생 시 프로그램이 자연스럽게 종료되도록 함.
  - 예외 생성 시 명확한 메시지를 포함하기. ("빈 값은 허용되지 않습니다.", "커스텀 구분자는 한 글자여야 합니다." 등)
- 기본 구분자 관련
  - 구분자가 연속될 경우 (1,,3)
  - 구분자 양쪽에 숫자외 다른 값이 있을 경우 (1:a)
  - 양수 외 숫자 포함된 경우 (0,1)or(-1,2)
  - 공백 허용하지 않음.
- 커스텀 구분자 관련
  - 커스텀 구분자는 한글자만 허용. 두글자 이상일 경우 예외처리.
  - 커스텀 구분자를 감싸는 "//", "\n"형식이 잘못된 경우
  - 커스텀 구분자가 숫자일 경우
  - "\n" 이후가 비어있을 경우

<br>

## 주요 클래스 구조 (설계)
| 클래스 | 역할 |
|--------|------|
| InputValidator | 입력 문자열의 유효성을 검증하고, 음수나 잘못된 값을 검사한다.|
| StringCalculator | 1. 커스텀 구분자 포함인지("//" 시작 여부) 판별하고, 적절한 클래스로 전달한다. <ul><li>커스텀 구분자 포함된 문자열 → CustomSeparatorParser로 전달 </li><li>커스텀 구분자 없는 문자열 → NumberAdder로 전달 </li></ul> 2. 계산 결과만을 반환한다.|
| CustomSeparatorParser | 커스텀 구분자("//"와 "\n" 사이 문자)를 인식하고, 숫자 부분 문자열을 분리해 NumberAdder에 전달한다. |
| NumberAdder | 순수 숫자 문자열과 커스텀 구분자를 전달받아, 문자열을 구분자로 분리해 정수로 변환하고 합계를 계산한다. |

<br>

## 고민 목록
- 설계에서부터 커스텀 구분자를 한글자만 허용해야 할 지, 두글자 이상도 허용해야 할 지 고민했다. 테스트 코드를 조회하니 두글자를 입력하는 테스트는 없어 보였고, 따라서 더 고민됐다. 기능 요구사항에 "문자열 앞부분의 '//'와 '\n' 사이에 위치하는 **문자**"라고 명시되어 있어, 이 부분은 한 글자인 '문자(character)'로 해석하는 것이 안전하다고 판단했다. 하지만 나중에 다중 구분자(한번에 여러 한글자 구분자들을 등록)를 추가하더라도 코드 구조를 크게 바꾸지 않도록 하고싶었다.
